## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|------------|
| A blind spot shared by EVERY review pass | Five independent passes -- planner, two plan-check rounds, code review, verifier -- all missed that a push event runs the workflow at the PUSHED TIP. Not one was careless; they all read the workflow in the working tree and none asked WHICH COMMIT'S COPY EXECUTES. | blocking | Re-running the same SHAPE of review cannot find this class. Ask what every pass is assuming in common, then check that assumption directly against the runtime, not the file. |
| A pre-registered expectation that is impossible by construction | The window plan's phase-9 observation asked for a `'linux'` producer on the Windows `publish-verify` leg. That job is a per-leg SELF round-trip that ENFORCES reader == producer, so the line requested is the exact condition its assertion rejects. The stale expectation sat in the SOURCE ROW and was inherited unexamined. | blocking | Before pre-registering, read the CODE that emits the line. Executed as written this spends the window and either leaves the row open for a false reason or closes it by loose-matching a neighbouring line. |
| A claim falsified by the session's own later commit | The plan said two workflow files were byte-identical and cited an empty diff. The previous commit -- adding the gate's reasoning as a COMMENT -- had already made that false. | blocking | State the property you actually need (executable identity), and verify it with a check that survives comment churn. |
| Gate that reads as coverage but asserts nothing | Now eight-plus instances across this session, and THREE were introduced BY fixes. | blocking | Of every gate: would an honest FALSIFIED pass? would writing NOTHING pass? would DELETING the guarded text pass? Check heading LEVEL, not just text. |
| Confident false zero | Five measured shapes: a literal spanning a line wrap (fired three times, once on the sweep correcting it); `rg -U` with `\s+` cannot bridge a wrap whose continuation carries a `#` (use `[\s#]+`); a SHAPE-anchored regex failing because a file records verdicts as headings not table rows; `git grep` needing `-e` for a dash-leading pattern; and `rg -rn` parsed as `--replace n`, which returns plausible prose with every match overwritten. | blocking | Check the EXIT CODE (1 = genuine no-match, 2+ = the command FAILED) and run a positive control on the same path before treating any zero as absence. |
| A number asserted as MEASURED that was never measured | Item 1's only verification gap, and item 2's shipped comment counted a CORRECT publish as an incident. | blocking | If a claim says MEASURED, run the command. Downstream files inherit provenance along with the number. |
