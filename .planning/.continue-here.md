## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|------------|
| Gate that reads as coverage but asserts nothing | Five instances this session, and a fix introduced two of them. lc3's `SRV-05` cardinality gate was satisfiable by DELETING the clause it guarded, with all 23 gates green. lpt's six vacuous presence gates all matched pre-existing text. lpt's `G7b` was DEAD -- its literal spanned a line wrap so it could never match, while being the only guard on a stale value. | blocking | Ask of every gate: would an honest FALSIFIED still pass? would writing NOTHING still pass? would DELETING the text without a replacement still pass? Apply the second question to the ADDITIVE direction too -- that is what found the six. |
| A fix that needs reviewing as hard as the original | `G8` was added to close a prose-only hole and did BOTH wrong things: passed on a per-ID section containing zero quotes (tokens satisfied downstream), and false-failed on legitimate downstream text. | blocking | Never treat a fix as safe because it addresses a known defect. Plan-check the revision, not just the plan. |
| A rule carried outside the conditions that made it safe | `G8`'s unbounded `tail -n +$EN` region was SAFE where iteration 1 checked it, because those sections append at EOF. Carried to a MID-FILE section it inverted. Same rule, different position, opposite outcome. | blocking | A region gate must bound its END, not only its start, unless the target section is provably last -- and "provably last" means the plan's own `<output>` ordering says so. All three lpt region gates now bound at the next `^## `. |
| Confident false zero | Three measured shapes, each reading as absence: a literal spanning a line wrap; `rg -U` with `\s+`, which cannot bridge a wrap whose continuation carries a `#` (use `[\s#]+`); and a SHAPE-anchored regex like `^\| (CORR-05\|RETAIN-05) ` returning exit 1 because the file records verdicts as headings, not table rows. | blocking | Check the EXIT CODE (1 = genuine no-match, 2+ = the command FAILED) and run a positive control on the same path before treating any zero as absence. |
| Ungated precise count in a sealed artifact | The plan was about to write "twenty boxes elsewhere" into the milestone audit; the real figure is ~93 across 19 files. A fresh false measured claim, in the artifact the task exists to make accurate. Root cause: the author's pattern was ``- [ ] ` `` and required a backtick, silently dropping every box starting with a word. | blocking | Either gate the number or omit it. Counts rot; a rotted count is what produced these eight debt items. |
| `git grep` with a dash-leading pattern | `git grep -n -F '- [ ]' -- f` fails with `error: unknown switch`. Every checkbox search hits this. | advisory | Use `-e`: `git grep -n -F -e '- [ ]' -- f`. |
