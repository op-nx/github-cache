## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI artifact -> comparator | The downloaded record JSON is untrusted input crossing a job boundary; it may be truncated, empty, or shaped differently than declared. |
| Comparator verdict -> merge decision | The compare job's verdict gates the branch. A comparator that passes for the wrong reason converts a live defect into a green leg. |
| Package source tree -> published tarball | `tsconfig.lib.json` emits every `src/**` subtree, so a new internal module ships to consumers unless both the exclusion and its assertion are added. |
