<objective>
Stamp producer attribution as Release asset METADATA, outside the lookup name, so the
namespace collapse CORR-02 performs does not also destroy incident-response attribution.

Purpose: OBS-03. CORR-02 removes the only in-name attribution the mirror has. The free-form
Release `label` field is verified to be optional, unconstrained, returned by
`listReleaseAssets`, and unable to influence either the asset filename or the download URL
(RESEARCH `### OBS-03`, read from the INSTALLED Octokit types). Landing the label BEFORE the
rename means attribution never lapses.

Output: a 4th positional `label` parameter across the `PublishClient` seam and its real
adapter, a per-run hoisted `mirrored-by: <os>` value, and machine-independent specs that
prove the label reaches the wire.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `publishMirror` engine -> `PublishClient` seam | untrusted-by-construction: the engine holds no Octokit and every network effect crosses this interface |
