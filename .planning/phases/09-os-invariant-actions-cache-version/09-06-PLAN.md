<objective>
Correct every statement this milestone just made false, and reword the warning that is about to fire.

Purpose: `enableCrossOsArchive: true` plus a workspace-relative path literal inverts a claim this repo
asserts in four places as a load-bearing invariant -- that restore is same-OS. Two of those four are
comments justifying a two-leg matrix, and one of them is the justification the "keep BOTH legs"
instruction rests on. Correcting the text without supplying a new reason would leave a later reader
with a documented argument for collapsing the matrix. Separately, the all-restore-MISS warning
currently offers the different-OS explanation as its FIRST candidate cause, which from this phase
forward sends every reader in the wrong direction.

Output: the reworded warning with its spec assertions, six documentation edits, and a
`DOCS_08_SITES` guard keyed on quoted phrases so the whole set fails loudly if any edit is later
reverted.

after the merge, on a `main` push. This plan closes the message and the docs; the reading is a
`human_needed` item against `09-ROTATION-SIGNAL.md`, carried into plan 09-07's record. Do not author an
acceptance check a pre-merge run could satisfy for it.

Vertical slice: one behavioural property (a reader gets the right diagnosis) closed end-to-end -- the
message, the docs that repeat its now-false premise, and a guard that fails when any of the six drifts
back.
