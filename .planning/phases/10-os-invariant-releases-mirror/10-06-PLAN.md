must land as a SINGLE unit so `lint` and `typecheck` stay green at exactly one commit and so the
enumerated expected-failure set is checkable in ONE test run. A partial RED would leave a
half-authored expectation set whose failing titles cannot be compared against the enumeration,
which is the only control that separates an intended RED from a defect in the plan. Every edit is
additive and spec-only, so the file count is breadth without depth.
