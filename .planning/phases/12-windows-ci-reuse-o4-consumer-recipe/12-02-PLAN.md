## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| fork PR -> `windows-11-arm` job holding `GITHUB_TOKEN` | untrusted content reaches a job that mints a loopback token and holds a write-trusted Actions-cache backend |
| Nx client -> loopback sidecar -> Actions cache service | the only path by which a Windows leg can read or write a shared cache entry |
| Windows task result -> Actions cache entry -> Releases mirror | a second OS's captured terminal output can now enter an anonymously-readable store for these three targets |

**The concrete delta is exactly one thing: a SECOND WRITER on an existing write path.** No new
credential, no new write PATH, no new public surface, no new package, no new network egress.
Established by the file list and by D-06's measurement of `select-backend.ts`.
