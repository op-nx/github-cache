<objective>
Close the phase on the landing evidence: run the full local battery, pre-register the expected
per-leg counts before the proving run, then record the observed run in `13-EVIDENCE.md` with its
scope stated honestly.

Purpose: the gate this phase builds is unobservable locally by construction — a spec runs in one
process on one OS and cannot observe a two-OS property. The behavioural proof is a run id. And
pre-registering the expected counts BEFORE the run is what makes the observation a prediction rather
than a description; Phase 12 established the idiom by committing its counts in `f5d03b0` before run
`30586177358`.

Output: a green battery, a pre-registration commit, and an evidence record that says exactly what
the run proves and what it does not.
