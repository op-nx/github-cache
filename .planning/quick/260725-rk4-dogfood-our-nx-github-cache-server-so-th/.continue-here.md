## Critical Anti-Patterns (do NOT repeat these)
- [TRUST]: Do NOT push-gate the wired jobs (`if: github.event_name == 'push'`) and do NOT omit `GITHUB_TOKEN` — `selectBackend` returns the *writable* backend on PRs too; without a token it degrades to the empty in-memory backend and the job caches NOTHING. Every wired job (push AND PR) passes `GITHUB_TOKEN` to `./start-cache-server`.
- [WINDOWS]: The `integration` matrix's `windows-11-arm` leg needs `shell: bash` (default is pwsh) and a `node`-generated loopback token (NOT `openssl`).
- [READINESS]: The sidecar readiness poll swallows curl's exit with `|| true` — never `|| echo 000`.
- [ENV SCOPE]: Never set `NX_*` at the workflow `env:` level — pre-set them per job in a regular step that writes `$GITHUB_ENV` before the background action adopts them.
- [KEY NAMESPACE]: Keep the real `nx-cache-<taskhash>` keys disjoint from the run_id-keyed proof-job keys (`nx-cache-<run_id>`, `nx-cache-cafe<run_id>`).
